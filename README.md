# KAMP X-ray 이물 탐지

KAMP X-ray 영상에서 작은 이물을 탐지하기 위한 데이터 정제, 객체 탐지 모델 학습, 평가 및 실험 분석 프로젝트입니다. 촬영 호기와 세션에 따른 성능 차이를 확인하고, 색상 표시 박스나 복원 흔적에 대한 의존성을 줄이는 학습 방법을 비교합니다.

이 저장소는 **실험 코드, 실행 설정, 핵심 지표, 선별된 실행 로그와 요약 보고서**를 관리합니다. 데이터셋과 모델 가중치는 별도로 준비해야 합니다.

## 프로젝트 개요

### 목표

- X-ray 영상의 작은 이물을 탐지하고 호기별 검출 성능을 비교합니다.
- 촬영 세션 단위로 데이터를 분리해 학습·평가 사이의 데이터 누출을 줄입니다.
- 이물 합성, 정상 영상 생성, 미끼 박스 및 ROI 학습의 효과를 검증합니다.
- 검출 정확도와 함께 정상 영상 오경보, 저대비 이물 및 작은 이물의 실패 사례를 분석합니다.

### 실험 구성

| 실험 계열 | 내용 | 데이터 분할 |
|---|---|---|
| YOLOv3-SPP | 통합·호기별 모델, 가중치 평균과 미세조정, 점·미끼·ROI 비교 | 정제 영상 2,532장: 개발 2,157장 / 고정 test 375장, 세션 단위 5-fold |
| 모델 비교 및 데이터 ablation | YOLOv8n, YOLO11s, RF-DETR-S, Qwen2.5-VL 실험과 Faster R-CNN용 Colab 코드 | 별도 통합 데이터 구성: 검증 80장 / test 80장, 정상 합성 평가셋 각 80장 |

두 실험 계열은 데이터 구성과 평가 조건이 다르므로 점수를 직접 비교하지 않습니다. 모델 비교의 기본 학습 설정은 4,403장이며, 후속 데이터 ablation은 조합별로 학습 장수가 달라집니다.

## 주요 실험 결과

### YOLOv3-SPP: 고정 test 375장

confidence threshold 0.07에서 평가한 결과입니다.

| 모델 | AP@0.5 IoU | 중심점 F1 | 중심점 Recall |
|---|---:|---:|---:|
| 통합 모델 | 0.9925 | 0.9743 | 0.9569 |
| 원시 가중치 평균 | 0.0000 | 0.0000 | 0.0000 |
| 가중치 평균 + BN 재보정 | 0.2521 | 0.3371 | 0.2630 |
| 가중치 평균 + 3 epoch 미세조정 | 0.9885 | 0.9933 | 0.9896 |

단순 가중치 평균은 유효한 검출 성능을 얻지 못했습니다. 평균 후 통합 데이터 미세조정은 중심점 F1과 Recall을 개선했으나 AP@0.5는 통합 모델보다 낮았습니다.

출처: [학습 및 평가 보고서](training/reports/TRAINING_REPORT.md), [지표 요약 CSV](training/reports/metrics_summary.csv).

### 점·미끼·ROI: 5-fold 통제 비교

동일한 fold별 출발 가중치에서 각 모델을 2 epoch 추가 학습한 결과입니다. 값은 fold 평균 ± 표본표준편차이며, 미끼 위치 검출률은 낮을수록 좋습니다.

| 학습 구성 | 원본 중심점 F1 | 합성 점 발견율 | 미끼 위치 검출률 |
|---|---:|---:|---:|
| 대조군 | 0.9628 ± 0.0201 | 0.2026 ± 0.0366 | 0.0849 ± 0.0453 |
| 합성 점 추가 | 0.9429 ± 0.0321 | 0.7120 ± 0.1111 | 0.2278 ± 0.1053 |
| 미끼 박스 추가 | 0.9643 ± 0.0214 | 0.1817 ± 0.0332 | 0.0260 ± 0.0206 |
| ROI 추가 | 0.9373 ± 0.0210 | 0.1884 ± 0.0771 | 0.0882 ± 0.0360 |

미끼 박스 추가는 원본 성능을 유지하면서 표시 박스 위치의 오검출을 줄였습니다. 합성 점 추가는 합성 점 발견율을 높였지만 원본 성능은 낮아졌습니다.

출처: [5-fold 비교 보고서](training/experiments/point_decoy_roi_5fold/CV_5FOLD_REPORT.md), [상세 실험 보고서](training/reports/POINT_DECOY_ROI_EXPERIMENT_REPORT.md).

## 실행 방법

### 1. 환경과 데이터 준비

- Mac 학습 파이프라인은 Apple Silicon의 PyTorch MPS와 `caffeinate`를 사용합니다.
- `run_all.sh`는 Python 3.12 → 3.11 → `python3` 순서로 실행 환경을 찾고 전용 `.venv`를 구성합니다.
- 주요 라이브러리는 PyTorch, torchvision, Ultralytics, RF-DETR, Transformers, PEFT, Accelerate, NumPy, OpenCV 및 Pillow입니다. 설치 명령은 `run_all.sh`에 있습니다.
- 원본·가공 데이터, 라벨과 필요한 가중치를 별도로 준비하고 YAML·스크립트의 로컬 경로를 자신의 환경에 맞게 수정합니다.
- YOLOv3 계열은 외부 YOLOv3 구현 경로(`--repo`), 모델 구성, 학습 목록과 초기 가중치를 별도로 요구합니다. 해당 구현과 학습 이미지 목록은 이 저장소에 포함되지 않습니다. 세션·fold 배정 기록은 `training/cv/fold_assignments.csv`에 있습니다.

### 2. Mac 모델 비교

데이터와 경로를 준비한 후 저장소 루트에서 실행합니다. 이 명령은 패키지 설치와 실제 모델 학습을 수행합니다.

```bash
bash "X-ray_실험/run_all.sh"
```

설치 → 스모크 테스트 → 본 학습 → 평가 순서로 진행합니다. 완료 단계는 `logs/*.done`으로 기록되며 재실행 시 건너뜁니다. 상세 준비 사항은 [실행 방법](X-ray_실험/실행방법.md)을 참고하세요.

### 3. 후속 데이터 ablation

1단계 환경과 데이터 준비가 완료된 후 실행합니다.

```bash
bash "X-ray_실험/phase2.sh"
```

### 4. Colab과 YOLOv3 실험

- Faster R-CNN: [Colab 노트북](X-ray_실험/colab/faster_rcnn_colab.ipynb)을 GPU 런타임에서 실행합니다. 별도 데이터 ZIP과 Drive 경로 준비가 필요합니다.
- YOLOv3: [학습 스크립트](training/scripts/train_yolov3_mps.py)의 인자와 [학습 보고서](training/reports/TRAINING_REPORT.md)의 조건을 확인합니다.
- 점·미끼·ROI 실험: [상세 보고서](training/reports/POINT_DECOY_ROI_EXPERIMENT_REPORT.md)의 실험 설계와 재현 경로를 참고합니다.

현재 의존성 설치는 버전이 고정되어 있지 않습니다. 기존 실험과 동일한 환경을 재현하려면 패키지 버전과 외부 모델 구현 버전도 맞춰야 합니다.

## 평가 기준과 해석 범위

- **AP50 / AP50-95:** 예측 박스와 정답 박스의 IoU에 기반한 검출 지표입니다.
- **중심점 F1 / Recall:** 예측 중심점이 약한 정답 박스 안에 들어가는지에 기반한 보조 지표입니다.
- **정상 영상 오경보율:** 정상 평가 영상 중 검출이 발생한 영상 비율입니다.
- **미끼 위치 검출률:** 정답이 아닌 인공 표시 박스 위치에 검출이 발생한 영상 비율입니다.
- **스트레스 평가:** 저대비 변형 등 인위적 조건에서 성능 변화를 확인합니다.

원본 라벨은 색상 박스에서 자동 추출한 **약한 라벨**입니다. 높은 점수가 실제 이물의 수동 정답 성능이나 현장 운영 성능을 보장하지 않습니다. ROI의 정답 위치 기반 crop은 위치를 미리 알고 수행한 상한선 실험입니다.

YOLOv3 실험의 무결함 영상은 1호기에 편중되어 있고, 고정 test는 여러 후보 비교에 사용되었습니다. 후속 모델 비교의 정상 합성 평가 역시 실제 정상 영상 평가와 구분해야 합니다.

## 파일 관리 정책

`.gitignore`는 허용 목록 방식입니다. 코드, 실행 설정, 핵심 지표, 선별된 실행 로그와 Markdown 보고서를 포함하며 새 경로나 파일 형식은 허용 규칙을 추가해야 합니다.

데이터셋, 이미지·라벨, 모델 가중치, 가상환경, 개별 예측, 캐시, 일반 로그, 압축파일 및 PDF/HWPX 보고서는 제외합니다. 기존 로컬 파일은 삭제하지 않습니다. 보고서 생성에 필요한 그림과 데이터도 별도로 준비해야 합니다.
