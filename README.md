# KAMP X-ray experiments

X-ray 이물 탐지의 데이터 처리, 모델 학습 및 평가 코드와 핵심 실험 지표를 관리합니다.

## 저장소 구성

- `scripts/`: 데이터 처리 코드
- `training/scripts/`: YOLOv3 학습, 교차 검증 및 실험 코드
- `training/runs/`, `training/experiments/`: 학습 설정, 학습 곡선, 평가 지표
- `training/reports/`: 실험 요약 보고서와 지표 CSV
- `X-ray_실험/`: 모델 비교 및 ablation 코드, 실행 설정, 평가 결과
- `X-ray_데이터셋_통합/`: 데이터 설정, 검증 결과 및 통합 보고서

실행 절차는 `X-ray_실험/실행방법.md`와 각 실험 보고서를 참고하세요.

## 파일 포함 정책

`.gitignore`는 허용 목록 방식입니다. 코드, 실행 설정, 핵심 지표와 Markdown 보고서만 Git에 포함합니다. 새로운 파일 형식이나 경로를 관리하려면 해당 허용 규칙을 추가하세요.

원본/가공 데이터, 이미지와 라벨, 모델 가중치, 가상환경, 개별 예측, 캐시, 로그 및 PDF/HWPX 보고서는 제외됩니다. 데이터와 가중치는 별도로 준비해야 합니다. 기존 코드와 설정의 로컬 경로는 실행 환경에 맞게 수정해야 합니다.
