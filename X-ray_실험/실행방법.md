# 실행 방법

## A. 맥에서 학습 (YOLOv8n · YOLO11s · RF-DETR-S · Qwen2.5-VL LoRA)

### 준비
1. 맥북 전원 어댑터 연결
2. Chrome 등 메모리를 많이 쓰는 앱 종료 (VLM 학습에 메모리 약 30GB 필요)

### 시작
1. Finder에서 `데스크탑 → kamp_ai → X-ray_실험` 폴더 열기
2. `학습시작.command` 더블클릭 → 터미널 창이 열리며 자동 시작
   - "확인되지 않은 개발자" 경고로 막히면: 파일 **우클릭 → 열기 → 열기**
   - 그래도 안 되면 터미널에 아래 한 줄 붙여넣고 Enter:
     ```
     bash ~/Desktop/kamp_ai/X-ray_실험/run_all.sh
     ```
3. **터미널 창은 닫지 마세요.** 창을 닫으면 학습이 멈춥니다. (잠자기는 자동으로 막힘)

### 진행 순서 (총 약 10~12시간)
| 단계 | 내용 | 예상 시간 |
|---|---|---|
| 설치 | 전용 가상환경(.venv)에 패키지 설치 | 5~10분 |
| 스모크 테스트 | 모델별 1epoch 짧게 실행 (실패하면 여기서 멈춤) | 15~30분 |
| YOLOv8n | 80epoch | 약 1~1.5시간 |
| YOLO11s | 70epoch | 약 3~4시간 |
| Qwen2.5-VL 제로샷 → LoRA 학습 | 기본 모델 평가 후 1,300장 × 2epoch | 약 2~3시간 |
| RF-DETR-S | 15epoch | 약 4시간 |
| 채점 | 전체 모델 자동 채점 | 수 분 |

### 중간에 멈췄다면
- `학습시작.command`를 다시 더블클릭 → 끝난 단계는 건너뛰고 이어서 실행
- 진행 상황: `X-ray_실험/logs/run_all.log` (단계별 상세는 `logs/단계이름.log`)
- 터미널에 `!!! ... FAILED`가 보이면 Claude에게 알려주세요. 로그를 보고 고친 뒤 다시 실행하면 됩니다.

## B. Colab에서 학습 (Faster R-CNN)
1. Google Drive에 `내 드라이브/kamp_colab` 폴더 만들기
2. `X-ray_실험/colab/xray_colab_data.zip`(176MB)을 그 폴더에 업로드
3. `X-ray_실험/colab/faster_rcnn_colab.ipynb`를 Colab에서 열기 (Drive에 올린 뒤 더블클릭 또는 colab.research.google.com → 업로드)
4. 메뉴 **런타임 → 런타임 유형 변경 → T4 GPU** 선택
5. 위에서부터 셀을 하나씩 실행 (▶ 버튼)
   - 첫 셀: Drive 연결 허용
   - 세 번째 셀(스모크 테스트)이 `DONE faster_rcnn_smoke`로 끝나면 네 번째 셀(본 학습, 약 2~3시간) 실행
6. 끝나면 Drive의 `kamp_colab/out` 폴더에서 아래 3개 파일을 내려받아 맥의 `X-ray_실험/preds/`에 넣기
   - `faster_rcnn.csv`, `faster_rcnn_meta.json`, `faster_rcnn_eval.json`
- 주의: Colab 탭을 너무 오래 방치하면 세션이 끊길 수 있습니다. 끊기면 셀을 처음부터 다시 실행하세요.
