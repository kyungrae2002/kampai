## 0. 한 줄 요약

**지금 데이터로 정할 수 있는 것은 "검증 목표"와 "필요한 표본 수"까지다.** 점수·영상 대비의 경계값(재검사선, 자동 통과선)은 실제 장비에서 독립 촬영한 흐릿한 이물·정상 제품 자료로 정해야 한다. 이번 학습 결과는 경계값을 확정하는 데가 아니라, **어떤 신호가 재검사 후보를 잘 골라내는지 미리 비교**하는 데 쓴다.

| 구분 | 지금 할 수 있음 | 지금 할 수 없음 |
|---|---|---|
| 판정 구조 | 3단계 흐름·규칙 정의 | — |
| 검증 목표 | 목표 탐지율(예: 90/95)·허용 재검사율 정의, 필요 표본 수 계산 | 목표 달성 입증 |
| 경계값 | 검증셋에서 후보 신호 비교, 곡선 그리기 | 운영 임계값 선언 |
| 정상 제품 | 합성 정상셋(`eval_sets/`)으로 경향 확인 | 실제 오경보율·재검사율 산정 |

## 1. 권장 판정 흐름

```
[촬영] → ① 영상 품질 게이트 ──불량──▶ 보류 + 재촬영 (모델 점수와 무관)
              │정상
              ▼
         ② 확정 탐지?  ──예──▶ 보류·격리 (재촬영에서 안 보여도 첫 경보 자동 취소 금지)
              │아니오
              ▼
         ③ 불확실 후보? ──예──▶ 재검사: 새 X-ray 재촬영 또는 사람 판독
              │아니오
              ▼
         ④ 통과 (단, 5절의 별도 검증을 통과한 뒤에만 자동 통과 허용)
```

| 단계 | 판단 근거 | 규칙 |
|---|---|---|
| ① 영상 품질 | 촬영 실패, 포화, 기준 시험편의 영상 품질 이탈 | 모델 판정 이전에 걸러냄. 품질 불량 영상은 통과 판정 불가 |
| ② 확정 탐지 | 높은 점수의 탐지 (상한 `T_high`) | 보류·격리. 두 번째 촬영에서 안 보였다는 이유만으로 취소하지 않음 |
| ③ 불확실 | 낮은 점수 대역(`T_low` ≤ 점수 < `T_high`), 낮은 국소 대비, 모델 간 불일치 | **새로운 관측**(재촬영) 또는 사람 판독. 같은 사진을 확대·선명화해 다시 추론하는 것은 새 관측이 아님 |
| ④ 통과 | 품질 정상 + 확정·불확실 후보 없음 | 실제 흐릿한 이물·정상 제품으로 탐지율·재검사율 목표를 검증한 뒤에만 자동화 |

주의: 탐지 모델의 confidence는 불량 확률로 보정돼 있지 않다. "점수 0.7 = 불량 확률 70%"로 해석하지 않는다.

## 2. 근거 수치와 정확한 의미

| 수치 | 정확한 의미 | 이 프로젝트에서의 사용 |
|---|---|---|
| 신호대잡음비 약 5 (Rose 기준) | 균일한 배경에서 저대비 물체를 사람이 구별하는 기준 (IAEA 영상물리 교재, AAPM TG-233) | **참고 지표만.** "대비 < 5 → 재검사" 같은 운영 규칙으로 쓰지 않음 (3절의 간이 확인 참고) |
| 90/95 POD | 목표 크기 이상 결함을 90% 이상 탐지함을 95% 신뢰하한으로 입증 (NASA NDE 표준 등 비파괴검사 관행) | 검증 방식의 예시. KAMP의 법정 합격선이 아님. 목표값은 팀이 정함 |
| 29 / 59 / 299개 | 독립 표본에서 **미탐 0개**일 때 탐지율 ≥ 90% / 95% / 99%를 95% 단측 신뢰로 뒷받침하는 최소 수 | 실제 시험편 수집 계획의 하한 (4절) |

계산식: 독립 표본 n개에서 미탐 0개이면 탐지율의 95% 단측 하한 = 0.05^(1/n). 목표 p 이상이 되려면 n ≥ ln(0.05) / ln(p).

미탐이 생기면 필요한 표본이 늘어난다 (정확 이항 Clopper–Pearson 단측 95%, 2026-10-04 계산):

| 목표 탐지율 | 미탐 0개 | 미탐 1개 | 미탐 2개 |
|---:|---:|---:|---:|
| 90% | 29 | 46 | 61 |
| 95% | 59 | 93 | 124 |
| 99% | 299 | 473 | 628 |

정상 제품의 재검사율(오경보율)도 같은 방식이다. 정상 n개에서 경보 0건이면 재검사율 95% 상한 = 1 − 0.05^(1/n) → 상한 5%를 보이려면 59개, 1%를 보이려면 299개.

**독립 표본 규칙:** 같은 원본의 증강본, 같은 촬영 묶음(세션)의 연속 프레임, 같은 시험편을 반복 촬영한 영상은 독립 표본 여러 개로 세지 않는다. 시험편·제품 단위로 센다.

## 3. 현재 데이터의 한계 (반드시 보고서에 적을 것)

1. **대비 5를 그대로 쓸 수 없다.** 공식 TXT 이물 1,147개에 대해 정제 영상의 이물 중심과 주변 밝기를 비교한 비표준 로컬 대비 지표에서 1,143개(99.65%)가 5 미만, 흐림 합성본은 1,147개 모두 5 미만이었다(기존 간이 확인). 균일 배경을 가정한 Rose 측정과 같지 않으므로, "대비 5 기준을 복사하면 사실상 전량 재검사"라는 경고로만 해석한다.
2. **흐림 합성 강도는 위험 경계가 아니다.** `processed/augmentation_noise_faint_v1`의 명암 약화 0.40–0.75, 노이즈 σ 2.5–9.5는 합성 강도일 뿐 장비에서 검증된 값이 아니다.
3. **실제 정상 제품 자료가 없다.** 공식 평가 사진은 이물이 있는 500장 중심이다. 이번 실험의 `eval_sets/검증_정상합성`, `테스트_정상합성`(각 80장)은 이물을 지운 **합성 정상**이라 실제 오경보율을 대신하지 못한다.
4. **기존 임계값을 복사하지 않는다.** 문서의 YOLOv8n 0.68106407은 이전 실험(xray_v2, 296/107/97 분할)의 검증 F1 최대 임계값이다. 이번 실험(새 분할)과도 다르고, 재검사선으로 설계된 값도 아니다.
5. **미탐은 두 종류다.** 기존 오류 분석(`20_모델선정과_평가_정리본.md` 14절)에서 YOLO 테스트 미탐 3개 중 점수 미달 1개, 박스 겹침 부족 2개였다. 점수 경계만 낮추는 규칙으로는 박스 불일치형 미탐을 해결하지 못한다.
6. **검증·테스트가 작다.** 각 80장. 모델 간 1~2%p 차이는 우연일 수 있으며, `*_eval.json`의 `F1_CI95`, `AP50_CI95`를 함께 본다.

## 4. 학습이 끝난 뒤 바로 할 작업 (이번 실험 결과로 가능한 범위)

모든 분석은 **검증셋(val, val_normal)에서만** 설계·결정하고, 테스트셋은 정한 규칙을 마지막에 한 번 적용해 확인한다. 테스트 결과를 보고 규칙을 고치지 않는다.

### 4.1. 결과 수집
- 입력: `preds/<모델>.csv`, `preds/<모델>_eval.json`, `preds/<모델>_meta.json` (YOLOv8n, YOLO11s, RF-DETR-S, Faster R-CNN, Qwen2.5-VL 제로샷·LoRA)
- 표로 정리: AP50, AP50-95, F1(+CI), 미끼 박스 오탐, 합성 정상 오경보율, 영상 AUROC, 처리 시간(장치 명시: MPS vs Colab GPU는 직접 비교 불가)

### 4.2. 미탐 유형 분해
- 모델별 검증 FN을 **박스 불일치**(근처에 예측은 있으나 IoU < 0.5)와 **점수 미달**(IoU ≥ 0.5 후보가 임계값 아래)로 나눈다.
- 박스 불일치가 많으면 → 판정을 "박스 일치"가 아닌 **영상·영역 단위 판정**(이물 있음/없음, 대략 위치)으로 바꾸는 것을 검토. 공장 판정은 박스 IoU보다 제품 단위 보류 여부가 중요하다.

### 4.3. 두 개의 경계(T_high, T_low) 후보 곡선
- 검증셋에서 점수 경계를 바꿔 가며 두 값을 함께 그린다.
  - 가로축: 합성 정상(`val_normal`)의 재검사율 (경보 또는 불확실로 분류된 비율)
  - 세로축: 실제 이물(`val`)의 미탐률 (확정·불확실 어디에도 안 걸린 비율)
- `T_high`: 확정 탐지 구간의 오경보가 충분히 낮은 점. `T_low`: 미탐을 원하는 수준까지 줄이는 점.
- **산출물은 "후보 곡선"이지 운영 임계값이 아니다.** 합성 정상과 80장 규모의 한계를 그래프에 표기한다.

### 4.4. 불확실 신호 비교 (무엇이 재검사 후보를 잘 고르는가)
각 신호가 "검증 오류(FN·FP)를 얼마나 잡아내는지" vs "재검사 대상이 얼마나 늘어나는지"를 비교한다.
| 신호 | 정의 예시 |
|---|---|
| 저점수 대역 | `T_low` ≤ 최고 점수 < `T_high` |
| 모델 간 불일치 | YOLO·RF-DETR·Faster R-CNN 중 한쪽만 검출(IoU 0.3 이상 대응 없음) |
| VLM 불일치 | 탐지 모델은 이물 있음, VLM은 `[]` (또는 반대) |
| 낮은 국소 대비 | 후보 영역 중심-주변 밝기 차 / 주변 잡음 (서술용, 단독 규칙 금지) |
| 미끼 근접 | 예측 중심이 복원 흔적(미끼 박스) 위치와 겹침 → 복원 흔적에 반응했을 가능성 |

### 4.5. 흐림 강도별 탐지 곡선 (합성)
- 검증·테스트 영상의 실제 이물만 명암 약화 0.2–1.0 단계로 약하게 만든 **평가 전용** 세트를 만든다 (학습 금지).
- 강도별 탐지율을 모델마다 그려 "어느 정도 흐려지면 급격히 놓치는지"를 본다.
- 이 곡선은 실제 시험편 수집 시 **어떤 흐림 범위의 시험편을 꼭 포함해야 하는지** 정하는 데 쓴다. 합성 결과를 실제 POD로 보고하지 않는다.

### 4.6. 점수 보정 점검
- 검증셋에서 점수 구간별 실제 정답 비율(신뢰도 곡선)을 그려 점수가 확률처럼 행동하는지 확인한다. 보정이 필요하면 별도 보정 자료로 수행하고, 테스트에서 맞추지 않는다.

## 5. 실제 장비 데이터 수집과 경계값 확정 절차

1. **목표를 먼저 정한다 (데이터 보기 전).** 예: "직경 X mm 이상의 흐릿한 이물을 90/95 POD로 탐지", "정상 제품 재검사율 상한 Y%". 팀·현장과 합의해 문서로 고정.
2. **필요 수를 계산한다.** 2절 표 사용. 호기(1·2·3호기)별·이물 크기별로 각각 목표를 주장하려면 그 칸마다 필요 수를 채운다.
3. **독립 촬영으로 모은다.**
   - 흐릿한 이물: 호기별·크기별·위치별(슬롯 끝 / 슬롯 밖 / 제품 경계) 실제 시험편
   - 정상 제품: 실제 생산품을 독립 촬영 (이물 제거 합성으로 대체 불가)
   - 기준 시험편: 영상 품질 게이트(①)의 기준값을 정하기 위한 주기적 촬영
4. **자료를 둘로 나눈다.** 경계값을 정하는 보정용(calibration)과 목표 달성을 확인하는 검증용(verification). 같은 시험편·세션이 양쪽에 들어가지 않게.
5. **보정용에서 `T_high`, `T_low`, 불확실 신호 조합을 정하고 고정한다.**
6. **검증용에서 한 번 확인한다.** 미탐 수·재검사 수와 신뢰 구간을 보고. 실패하면 목표·모델·수집 범위를 다시 정하고 **새 검증 자료**로 다시 확인.
7. **운영 중 감시.** 재검사로 확인된 결과를 누적해 미탐·재검사율 추이를 주기적으로 점검.

---

## 6. 하지 말 것

- 논문·표준의 수치(대비 5, 0.9 등)를 이 장비의 임계값으로 그대로 사용
- 기존 실험의 임계값(예: 0.68106407)을 재검사선으로 복사
- 같은 영상의 증강본·연속 프레임을 독립 표본으로 계산
- 같은 사진을 확대·선명화해 다시 추론한 결과를 "재검사"로 간주
- 두 번째 촬영에서 안 보였다는 이유만으로 첫 확정 경보 자동 취소
- 합성 정상(`eval_sets/`)의 오경보율을 실제 공장 오경보율로 보고
- 테스트셋 결과를 보고 임계값·규칙 수정
- 탐지 confidence를 보정 없이 불량 확률로 표기
