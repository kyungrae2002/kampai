## 1. 한 줄 요약

## 5. 주의할 점

1. **기존 분할과 섞으면 누출된다.** 원본 BMP 해시로 기존 `processed/curated` 분할과 대조한 결과:

   | 이 데이터셋 → curated | 학습 | 검증 | 테스트 |
   |---|---:|---:|---:|
   | 학습 (340) | 246 | 68 | 26 |
   | 검증 (80) | **57** | 0 | 23 |
   | 테스트 (80) | **47** | 9 | 24 |

   이 데이터셋의 테스트 80장 중 47장은 curated에서 학습용이었다. 기존 curated·processed 묶음이나 docs의 xray_v2(296/107/97 분할)로 학습한 모델을 이 테스트셋으로 채점하면 점수가 부풀려진다. **이 데이터셋은 자체 분할 그대로, 다른 데이터셋과 섞지 않고 쓰는 것을 권장한다.** (xray_v2는 이 폴더에 없어 직접 대조하지 못했다.)
2. **의사 라벨 2,016장은 포함돼 있지 않다.** `split_report.csv`에는 `train_pseudo` 2,016행이 있지만 ZIP에는 해당 영상·라벨이 없다. README의 학습 2,492장은 사람 라벨 원본 340장과 그 증강본만으로 계산한 수치라 README와 실제 파일은 일치한다. 의사 라벨까지 쓰려면 별도 파일을 받아야 한다.
3. **검증·테스트가 작다.** 각 80장(세션 16개·22개)이라 모델 간 1~2%p 차이는 우연일 수 있다.
4. **합성본은 독립 표본이 아니다.** 학습 2,492장 중 실제 촬영은 340장이고, 나머지 2,152장은 이 340장에서 만든 변형이다.
5. **정상 영상은 합성이다.** `4_이물전부제거_정상영상`은 이물을 지운 영상이지 실제 정상 제품 촬영본이 아니다.

## 6. 원본 처리 방식 요약 (원본 README 기준)

- 공통: 검사기 컬러 박스 검출(max−min ≥ 80, max ≥ 180) → Telea 인페인팅, 정답 없는 자리에도 같은 모양 박스를 그렸다 지우는 미끼 박스, 제품 잡음 수준의 노이즈 재주입.
- 분할: 중복 제거 후 60초 이내 연속 촬영을 한 묶음으로 보고, 라벨 있는 묶음에서 호기별 15%씩 검증·테스트(seed 0).
- 박스 크기 중앙값은 모든 방법에서 약 10×10px로 원본과 합성이 비슷하다(합성 최대 24×25px).
