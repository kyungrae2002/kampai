# KAMP YOLOv3-SPP 학습 및 평가 보고서

## 결론

세션 누출을 차단한 5-fold 교차검증과 고정 test 평가를 완료했다. 통합 모델은 안정적으로 동작했고, 호기별 모델의 **단순 가중치 평균은 실패**했다. 다만 이미지 수 가중 평균 뒤 통합 데이터로 3 epoch 미세조정한 모델은 통합 모델보다 높은 test 성능을 보였다.

현재의 잠정 배포 후보는 `training/runs/machine_weight_ensemble/finetuned/last.pt`이다. 단, 자동 추출된 약한 라벨에 대한 결과이며 실제 이물 정답 성능을 뜻하지 않는다.

## 실행 조건

- 하드웨어: Apple M5 Pro 내장 GPU 16코어
- 가속기: PyTorch MPS (`mps`)
- PyTorch: 2.14.0
- 구조: YOLOv3-SPP, 225 layers, 62,573,300 parameters
- 입력: 320 × 320
- batch size: 4, gradient accumulation: 4
- optimizer: AdamW, cosine learning-rate schedule
- 초기값: 공식 Darknet-53 backbone `darknet53.conv.74`
- 초기값 SHA-256: `2495c2690283e4e0bc2050cbd4660b77a8074e14e9c11150c6412fd63db496a7`
- 기존 색상 박스 학습 체크포인트 `weights/last.pt`: 사용하지 않음
- 학습 epoch: 교차검증·통합·호기별 모델 각 6 epoch
- 앙상블 후 미세조정: 3 epoch, learning rate 0.0003
- 운영 confidence threshold: 5-fold 최적값 중앙값인 0.07로 사전 고정

## 데이터 분리

- 고유 이미지: 2,532장
- 개발 세트(train+val): 2,157장, 545개 촬영 세션, 3,779개 박스
- 고정 test: 375장, 95개 촬영 세션, 673개 박스
- 5-fold 단위: 이미지가 아니라 `session_id`
- train/validation 및 test 사이 세션 중복: 0
- 개발 세트 무결함 이미지 89장은 전부 1호기이며, 2·3호기에는 무결함 예제가 없음

| 1 | 0.100 | 0.9785 | 0.9520 | 0.9299 | 0.9751 | 1.0000 |
| 2 | 0.095 | 0.9756 | 0.9420 | 0.9650 | 0.9200 | 1.0000 |
| 3 | 0.060 | 0.9634 | 0.9258 | 0.9186 | 0.9331 | 0.9444 |
| 4 | 0.055 | 0.9828 | 0.9723 | 0.9545 | 0.9908 | 1.0000 |

호기별 중심점 recall 평균은 1호기 0.9970, 2호기 0.9975, 3호기 0.8658이었다. 3호기는 fold 표준편차도 0.0860으로 가장 불안정했다.

### 호기별 중심점 recall

| 모델 | 1호기 | 2호기 | 3호기 |
|---|---:|---:|---:|
| 통합 모델 | 0.9746 | 1.0000 | 0.8959 |

평균 후 미세조정 모델은 3호기 recall을 0.8959에서 0.9955로 높였고, 전체 false positive는 중심점 기준 5건에서 2건으로 줄였다. 16개 무결함 test 영상은 두 모델 모두 전부 무검출이었다.

## 해석과 제한

1. **단순 가중치 평균은 사용할 수 없다.** 세 모델이 같은 초기값에서 출발했지만 독립 AdamW 학습으로 서로 다른 최적화 분지로 이동했다. 파라미터 평균점은 유효한 검출기가 아니었다.
2. **평균 후 통합 미세조정은 유효했다.** 평균점을 통합 데이터로 3 epoch 재정렬하자 성능이 복구되고 3호기 성능이 개선됐다. 이 결과물은 엄밀한 의미의 추론 앙상블이 아니라 `weight soup + joint fine-tuning`이다.
3. **무결함 데이터 편향이 크다.** 무결함 89장과 test 무결함 16장이 모두 1호기다. 따라서 2·3호기 무결함 specificity는 측정할 수 없다.
4. **라벨은 약한 라벨이다.** 색상 사각형 위치에서 자동 추출됐으며 clean 이미지는 해당 픽셀을 inpainting했다. 높은 점수가 실제 이물 특징뿐 아니라 미세한 복원 흔적이나 촬영 패턴을 학습한 결과일 수 있다.
5. **test 세트는 여러 후보 비교에 사용됐다.** 따라서 최종 후보 선택까지 고려하면 더 이상 완전히 독립적인 holdout이 아니다. 생산 승인 전에는 사람이 새로 박스를 그린 별도 세트가 필요하다.

## 권장 다음 단계

1. 각 호기에서 무결함 영상을 최소 100~200장씩 추가한다.
2. 세션을 골고루 뽑아 최소 300장의 수동 박스 정답 세트를 별도로 만든다. clean 이미지의 복원 품질도 함께 검수한다.
3. 잠정 후보 `finetuned/last.pt`를 새 수동 정답 세트에서 IoU AP, recall, 오검출/1,000장으로 재평가한다.
4. 진짜 호기 분산학습을 원하면 독립 완주 모델을 평균하지 말고, 공통 global checkpoint에서 각 호기가 1 local epoch만 학습한 뒤 가중 평균하는 FedAvg round를 3~5회 반복한다. 각 round에 1호기 무결함 replay pool을 2·3호기 학습에도 포함해야 한다.
