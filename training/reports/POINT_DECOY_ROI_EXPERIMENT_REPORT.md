# KAMP YOLOv3 점·미끼 박스·ROI 실험 (2026-10-01)

## 목적과 판정 범위

KAMP X-ray 프레임에서 작은 이물 포인트를 찾는 YOLOv3-SPP가 실제 타겟 이외의 사각형 표시나 복원 흔적에 의존하는지 진단하고, 학습 데이터 구성을 비교했다. 모든 지표는 기존 색상 박스에서 자동 추출한 **약한 라벨** 기준이다. 실제 이물 검출 성능 또는 연속 영상 운영 성능으로 해석하면 안 된다.

## 데이터와 실험 설계

- 기존 정제 세트 2,532장의 세션 분할을 유지했다. 통제 비교는 fold 1 학습 1,727장·검증 430장, 95개 별도 세션의 고정 test 375장을 사용했다. train/val/test의 세션 교집합은 0이다.
- 4개 미세조정 모델은 동일한 fold 1 YOLOv3-SPP 체크포인트에서 출발했다. 각 학습 목록은 원본 1,727장 + 변형 600장 = 2,327장으로 맞췄다. 대조군은 600장을 그대로 반복했다. 모두 Apple M5 Pro 내장 GPU(MPS), 320px, batch 4, accumulation 4, seed 20261001, 2 epoch, learning rate 0.0001이다.
- 검증은 원본 430장, 합성 점 430장, 미끼 박스 430장, 정답 위치 중심 ROI crop 430장이다. test는 각각 375장이다. confidence threshold **0.07**을 사전에 고정했으며, test로 재조정하지 않았다.
- 합성 점: 실제 X-ray 영상에서 제품 내부 픽셀을 우선 선택하되 기존 정답과 떨어진 임의 위치에 반경 3–5px의 어두운 점을 합성하고, 생성 좌표에서 YOLO 박스(점 직경 + 8px)를 정확히 기록했다. 제품 픽셀 후보가 부족한 10/1,405건은 배경 위치가 선택됐다. 이것은 **합성 점의 정답**이지 실제 이물의 수동 정답이 아니다.
- 미끼 박스: 정답과 떨어진 제품 내부에 원본 표시와 유사한 빨강/노랑 1px 사각형을 그리되 정답 라벨은 추가하지 않았다. 박스 중심의 오검출을 별도로 셌다.
- ROI crop: 기존 약한 정답 주변 160×160px을 잘랐다. 학습 시 ±12px 위치 흔들림을 주고, 잘린 영역 밖 정답은 제거했다. ROI 검증은 정답 위치를 알고 자른 **oracle 실험**이며 실제 전체 영상 추론과 다르다.

## 동일 fold의 통제 비교: 검증 430장

| 모델 | 원본 중심점 F1 | 원본 FP | 합성 점 발견 / 430 | 미끼 영상 F1 | 미끼 위치 검출 / 430 | ROI 중심점 F1 |
|---|---:|---:|---:|---:|---:|---:|
| 출발 YOLOv3 | 0.9470 | 73 | 86 | 0.9203 | 26 | 0.4796 |
| 원본 반복학습 대조군 | 0.9711 | 40 | 107 | 0.9528 | 19 | 0.4392 |
| 합성 점 추가 | 0.9523 | 73 | **353** | 0.9183 | 43 | **0.8683** |
| **미끼 박스 추가** | **0.9755** | **33** | 92 | **0.9743** | **2** | 0.4365 |
| ROI crop 추가 | 0.9556 | 61 | 130 | 0.9132 | 43 | 0.7652 |

원본 중심점 F1은 예측 중심이 약한 정답 박스 안에 들어가는지를 기준으로 한다. 같은 원본에서 IoU@0.5 AP는 대조군 0.9851, 미끼 모델 0.9864였다. 합성 점 재현율 향상은 매우 크지만 원본·미끼 성능이 하락했다. ROI 학습은 crop에 대한 적응은 유도했으나 원본 영상과 미끼 영상에서 불리했다. 특히 ROI 모델의 crop 검증은 TP 686, FP 350으로 재현율에 비해 오탐이 많았다.

## 고정 test 375장: 검증에서 선택한 미끼 모델의 재확인

| 모델 | 원본 중심점 F1 | 원본 TP/FP/FN | 미끼 영상 F1 | 미끼 위치 검출 / 375 |
|---|---:|---:|---:|---:|
| 원본 반복학습 대조군 | 0.9658 | 663 / 37 / 10 | 0.9465 | 19 |
| **미끼 박스 추가** | **0.9699** | 661 / 29 / 12 | **0.9664** | **3** |
| 기존 통합 최종 모델 | 0.9743 | 644 / 5 / 29 | 0.9300 | 43 |
| 기존 가중치 평균 후 미세조정 모델 | **0.9933** | 666 / 2 / 7 | 0.9666 | 18 |
| 기존 최강 모델 + 미끼 추가 학습 | 0.9926 | **667 / 4 / 6** | **0.9889** | 5 |

같은 출발점·학습량을 통제한 비교에서 미끼 학습은 375장 중 미끼 위치의 검출을 19건에서 3건으로 줄였다. 단 원본 타겟도 2개 덜 찾았다. 기존 두 최종 모델은 전체 개발 데이터로 학습한 반면 위 두 실험 모델은 fold 1의 1,727장만 학습했으므로, 이 표로 가중치의 절대 우열을 결정해서는 안 된다.

추가로 기존 최강 가중치에서 원본 개발 이미지 2,157장 + 미끼 변형 1,030장, 총 3,187장으로 2 epoch(learning rate 0.00003) 학습했다. 원본 test 중심점 F1은 0.9933→0.9926으로 거의 유지됐고, 미끼 영상 F1은 0.9666→0.9889로 올랐다. 원본 영상의 TP/FP/FN은 666/2/7에서 667/4/6으로 바뀌었다. 이 결합은 **전체 개발 데이터를 사용해 별도 검증 세트가 없으며**, test 결과는 탐색적 확인이다.

### 학습에서 보지 않은 미끼 스타일

test 375장에 파랑/초록색, 두께 2px, 약 1.5배 크기의 미끼를 별도로 그렸다. 두 모델 모두 이 스타일로 학습하지 않았다.

| 모델 | 새 스타일 영상 중심점 F1 | FP | 미끼 위치 검출 / 375 |
|---|---:|---:|---:|
| 기존 가중치 평균 후 미세조정 모델 | 0.9237 | 103 | 47 |
| **기존 최강 모델 + 미끼 추가 학습** | **0.9801** | **20** | **8** |

새 스타일에서도 취약성이 크게 줄었다. 그러나 이것 역시 인위적 사각형 스트레스 테스트이며, 현장 이물의 독립 정답 검증을 대체하지 않는다.

## 결론

세 변형 중 **미끼 박스 음성 예시**가 현 데이터의 원본 성능을 유지하면서 사각형에 대한 오탐을 가장 일관되게 낮췄다. 이에 따라 기존 최강 가중치를 미끼 예시로 추가 학습한 `runs/decoy_on_weight_soup/last.pt`가 **이번 약한 라벨·합성 미끼 범위의 잠정 후보**다. 그러나 색상 사각형은 인공적인 교란이므로, 미끼를 무시하게 됐다는 것이 실제 이물을 본다는 증명은 아니다. 합성 점은 합성 도메인 전용 능력을 크게 개선하지만 실물 일반화의 증거가 없다. ROI crop은 현재 방식 그대로 배포하지 않는다. ROI의 oracle 점수로 전체 영상 성능을 주장할 수 없고, 별도 후보 영역 제안 또는 타일 추론까지 포함해 평가해야 한다.

고정 test는 이전 프로젝트에서 여러 모델 비교에 사용됐고, 라벨도 자동 추출됐다. 또한 무결함 영상은 1호기에만 있어 2·3호기의 정상 프레임 오탐율은 아직 측정 불가하다. 다음 신뢰도 관문은 새로운 촬영 세션의 각 호기 정상/이물 영상을 확보하고 사람이 직접 그린 타겟 정답으로 프레임·세션·연속 영상 지표를 평가하는 것이다.
